# Fanne Linux brand assets

These are the original transparent PNG assets supplied by the Fanne Linux
project:

- `fanne-mark.png`: symbol without the wordmark
- `fanne-logo-black.png`: wordmark for light backgrounds
- `fanne-logo-white.png`: wordmark for dark backgrounds

Build-specific sizes and backgrounds are derived from these files. Do not
stretch the images or change the symbol's proportions.

# Roadmap

## Milestone 0: Bootstrap

- [x] Define the Debian Live build pipeline.
- [x] Add an AMD64 XFCE package profile.
- [x] Add Fanne system identity and English defaults.
- [x] Add local validation and continuous integration.
- [ ] Produce and boot-test the first development ISO.

## Milestone 1: Identity

- [ ] Create the official logo, color palette, and typography rules.
- [ ] Package Fanne wallpapers and desktop defaults.

## Milestone 2: Hardware quality

- [ ] Establish AMD, Intel, and NVIDIA graphics test coverage.
- [ ] Test common Wi-Fi, Bluetooth, audio, suspend, and laptop controls.
- [ ] Define a hardware-reporting process for testers.
- [ ] Document Secure Boot strategy and signing requirements.

## Milestone 3: Distribution infrastructure

- [ ] Build Fanne packages in a dedicated APT repository.
- [ ] Sign repository metadata and release images.
- [ ] Publish release notes, checksums, and installation documentation.
- [ ] Define stable and development update channels.
